# GojoTech

A modern e-commerce storefront built with HTML, JavaScript, Tailwind CSS, and npm.

GojoTech is a frontend-focused technology store designed to simulate a real-world e-commerce experience, including product discovery, filtering, cart management, wishlist functionality, and checkout flow.

---

## Overview

GojoTech provides a complete frontend shopping experience without relying on a backend.

The project focuses on building a production-style interface using vanilla JavaScript and modern frontend practices rather than relying on a JavaScript framework.

Product, cart, and wishlist data are handled on the client side, with browser `localStorage` used to persist shopping cart and wishlist state.

---

## Features

### Product Discovery

- Browse the complete product collection
- Search products by:
  - Name
  - Description
  - Category
- Filter products by category
- Sort products by:
  - Featured
  - Price: Low to High
  - Price: High to Low
  - Rating
  - Name
- Clear active filters
- Dynamic product count

### Product Details

- Dedicated product detail pages
- Dynamic product loading using URL parameters
- Product images
- Product descriptions
- Ratings
- Pricing
- Add to cart functionality
- Wishlist functionality

### Shopping Cart

- Add products to cart
- Increase/decrease product quantities
- Remove products
- Persistent cart state using `localStorage`
- Dynamic cart item count
- Cart subtotal
- Cart total
- Empty cart state

### Wishlist

- Add products to wishlist
- Remove products from wishlist
- Persistent wishlist state using `localStorage`
- Dedicated wishlist page
- Add wishlist products directly to cart
- Empty wishlist state

### Checkout

- Checkout page
- Order summary
- Customer information
- Shipping information
- Order completion flow

### UI / UX

- Responsive design
- Mobile navigation
- Hover interactions
- Product card animations
- Scroll reveal animations
- Smooth scrolling
- Accessible labels and buttons
- Responsive layouts for different screen sizes
